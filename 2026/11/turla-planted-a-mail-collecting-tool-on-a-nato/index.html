Turla planted a mail-collecting tool on a NATO state's Microsoft email server

Romania's state email ran on Microsoft servers outside European control while a Turla tool collected NATO- and EU-related messages, and a second Romanian system was found compromised weeks later. Government mail must move to European-run servers, and that decision belongs in the next budget cycle.

11 November 2026

A ministry's inbox must not run on someone else's server. On 10 November, ESET named the toolset it found on the Exchange server of a governmental organisation in Romania: Cereal, planted by Turla, the group researchers assess sits inside Russia's FSB. Inside that mail system, a component called CerealBox was configured to collect messages involving NATO and EU institutional addresses. While Romania's politicians called for a NATO mission in the Black Sea, after Russian drones had crashed on its territory through 2025, the mail of its own state was being read from the inside, on Microsoft's software. We call that a dependence, and a self-inflicted one.

The technique leaves almost nothing to catch. ESET's researchers describe a backdoor, CerealNeuron, that does not phone home to any server a defender can block. It 'passively listens for incoming web requests on paths that look like ordinary Exchange traffic', with no domain, no IP address and no timing patterns to fingerprint. ESET named the toolset about eleven months after the first infection the researchers found. ESET researcher Matías Porolli wrote it plainly: for Turla, Exchange servers are 'durable collection points, internal execution hubs, and a suitable environment for hiding sophisticated .NET tradecraft'.

Nobody should file this under bad luck. Turla has turned a compromised Exchange server into its own operational infrastructure before, and only a handful of spy groups know the technique at all. On a server like this, code reads every message a government official sends to a colleague, selects the ones worth having, compresses and encrypts them and stores them on disk for later collection. ESET says the toolset shows Turla can run a slow, careful, long-term intrusion built entirely inside Microsoft's email software. No patch or official response from Microsoft was reported. And this was no isolated breach: on 28 November 2025, ESET found the same toolset inside Kazakh state mail built on the same Microsoft software, in a country that has since begun deporting Russian exiles and regime critics. A mail system someone else controls is not a leak that happens once.

The objection is fair on its own terms: attribution rests on researchers' assessment, not a court ruling, and no captured classified message has been confirmed, only a filter tuned to NATO and EU traffic. But the filter itself is the finding. A state does not wait for a leaked document to secure its cabinet correspondence; it removes the switch someone else's hand is resting on.

The second case settles it: ESET found another Romanian government system compromised under the same Turla operation on 23 December 2025. Migration off foreign servers costs money, which is exactly why the answer belongs where budgets are decided once. The Commission, together with each national cabinet, must write a procurement rule that no governmental email system runs on servers outside European control, and must place those systems under European technical oversight as critical infrastructure, in the next budget cycle.
